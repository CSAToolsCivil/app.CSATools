Chào anh/chị 👋

Hỏi gì về CSA Tools cũng được: cài đặt, đăng nhập, cách dùng file tính Excel, tool vẽ AutoCAD, lỗi thường gặp… Có thể dán ảnh chụp lỗi, gửi file Excel để kiểm tra dữ liệu nhập.

Kho CSA (không tốn token)Gõ “lưu ý: …” để nhắn CSA AI ghi nhớ.

Kiểm tra bản vẽ kết cấu

Tải file .DXF (AutoCAD: SAVEAS → DXF). Kiểm tra layer, chữ, DIM, trục, nhãn dầm, ký hiệu cột/lỗ mở/sàn, khung tên theo quy tắc MBKC. File chỉ xử lý trên máy anh/chị, không gửi lên mạng.
Kéo thả hoặc bấm để chọn file DXF
Trong AutoCAD: APPLOAD file LISP → gõ CSACHECK để vẽ vòng đánh dấu + số thứ tự lỗi (layer CSA_CHECK, không in). Xoá: CSACHECKCLEAR.

Nhận xét của AI

Dựng mặt bằng kết cấu từ mặt bằng kiến trúc

Tải mặt bằng kiến trúc .DXF → chọn layer trục, cột, tường, lỗ mở → CSA AI tạo file LISP vẽ MBKC trong AutoCAD theo quy tắc: kế thừa trục/cột, dầm chính nối cột, dầm đỡ tường, dầm bao lỗ > 2 m², tiết diện sơ bộ, đặt tên dầm, DIM 4 phía, ký hiệu sàn, khung giấy.
Kéo thả hoặc bấm để chọn file DXF kiến trúc

1. Chọn layer

Đã tự gợi ý theo tên layer – kiểm tra lại.

2. Thông số (bắt buộc xác nhận)

– khoảng cách 2 nét tường

Hatch cột

Kết quả

AutoCAD: mở bản vẽ (có thể chính file kiến trúc) → APPLOAD chọn file LISP → gõ CSA_MBKC. MBKC vẽ đúng toạ độ kiến trúc, đúng 15 layer KCS, style Arial 0.7, DIM 2.2-N, LTSCALE = 10N.
